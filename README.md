## 🚀 Featured Projects

### 🟠 [AWS Automated ETL Pipeline — Serverless Event-Driven](https://github.com/Khushi10-DE/aws-automated-etl-pipeline)
> **S3 · Lambda · Glue · DynamoDB · EventBridge · SNS** *(In Progress)*

Fully serverless, event-driven ETL pipeline on AWS. Files landing in **S3** trigger **EventBridge** rules which invoke **Lambda** for preprocessing, pass data through **AWS Glue** for transformation, and load results into **DynamoDB**. **SNS** sends automated email alerts on pipeline success or failure.

`AWS S3` `AWS Lambda` `AWS Glue` `DynamoDB` `EventBridge` `SNS` `Python`

- ✅ 100% serverless — zero infrastructure management
- ✅ Event-driven architecture with end-to-end monitoring
- ✅ Automated failure alerts via SNS email notifications

### 🔶 [Databricks Medallion Architecture Pipeline](https://github.com/Khushi10-DE/databricks-medallion-pipeline)
> **Bronze → Silver → Gold Lakehouse | Delta Lake | PySpark**

End-to-end lakehouse pipeline on **Databricks** using **Delta Lake**, **PySpark**, and **Auto Loader**. Implements the full Medallion Architecture with structured streaming, Unity Catalog governance, and Gold-layer KPI tables for BI consumption.

`Databricks` `PySpark` `Delta Lake` `Auto Loader` `Unity Catalog` `SQL`

- ✅ Incremental ingestion with Auto Loader (no duplicate processing)

- ✅ 4 Gold KPI tables — hourly demand, revenue, location, payment analysis
